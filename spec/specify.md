# 功能规格：多模态素材库 MVP

**功能分支**：`001-multimodal-asset-library`
**状态**：实施中
**技术约束**：Next.js、TypeScript、Tailwind CSS、shadcn/ui、pnpm

## 用户故事

### P1：上传并分析本地素材

内容运营人员可以一次选择一个或多个图片/视频，在固定高度的滚动列表中逐项悬停预览，并看到各自的真实上传进度、处理状态以及明确失败原因。每个素材以独立请求上传，成功后系统异步生成描述、标签和相应结构化分析。

验收条件：

1. 文件名扩展名为 JPEG、PNG、WebP 的图片不超过 20 MB 时可提交；实际内容为另一种受支持图片格式时，worker 转换成扩展名指定的真实格式。结果包含描述、分类标签和 OCR 或不可用原因。
2. 文件名扩展名为 MP4 的自包含可解码视频不超过 200 MB 时可提交；worker 将其归一化为 H.264/yuv420p MP4，并在服务端提取 1–5 张带时间点的 JPEG 关键帧。结果包含视觉描述、主题、标签、视觉分段、关键时间点和时间轴。
3. 音频、URL/播放列表、图片伪装视频、损坏文件、转换不完整和超限文件被拒绝，并显示具体原因。
4. 视频不足或等于 5 秒时提取 `ceil(时长秒数)` 帧，超过 5 秒时固定提取 5 帧；各帧位于等分区间中点，长视频对应 10%、30%、50%、70%、90%。
5. Responses 协议或禁用视频能力时，视频任务失败为 `model_video_unsupported`，不得绕过关键帧方案或静默改用其他分析方式。

### P2：审核、编辑和正式入库

用户可以编辑名称、描述和标签后正式入库，也可以在上传时选择分析完成后直接入库。删除过的模型标签在重新分析后不得自动恢复。

### P3：浏览和维护素材

概览将所有上传成功且未删除的素材分为“已入库”和“待入库”两个视图，默认打开已入库，每页按 4 列 × 2 行展示 8 个素材。待入库包括排队、分析中、失败以及分析完成待确认的素材，并明确标注状态；分析完成且待审核的素材可在概览直接入库。详情展示上传信息、正规化后媒体预览、处理状态、分析结果和最终元数据，并允许按上传时的文件名下载正规化后的媒体。

## 功能需求

- 上传页允许一次选择多个本地文件，并按选择顺序为每个素材发送独立 multipart 请求；图片与视频分别使用专用接口，视频关键帧由服务端提取。
- 上传框保持固定高度；素材列表一行一个文件，默认显示文件名，悬停或聚焦时展开本地预览，超出区域可滚动。
- 图片目标格式支持 JPEG、PNG、WebP；视频目标格式支持 H.264/yuv420p MP4，并允许 worker 从受支持的本地单文件视频容器转换。
- 上传限制默认为图片 20 MB、视频 200 MB，并允许环境变量覆盖。
- 处理状态为 `queued`、`validating`、`analyzing`、`completed`、`failed`。
- 审核状态为 `pending_review`、`published`、`deleted`。
- 支持 OpenAI Chat Completions 和 Responses 两种兼容协议。
- 模型配置和密钥只通过环境变量注入。
- Chat Completions 视频分析使用带时间点标注的多图片输入；Responses 默认不支持视频。
- Qwen3.7 结构化素材提取默认关闭思考模式，并允许通过环境变量显式覆盖。
- worker 在 `validating` 阶段完成媒体真实格式校验和必要转换，再使用 FFmpeg 抽取 JPEG 关键帧；关键帧随素材持久化，重试时直接复用。
- 支持上传状态、素材分页、详情、编辑、发布、重试、软删除和 Range 媒体读取 API。
- 上传页离开后停止页面轮询，但已入队任务继续由 worker 处理；worker 使用任务心跳并周期恢复失联任务。
- 素材上传成功后立即出现在概览；概览在存在非终态素材时自动刷新，并支持对已完成待审核素材直接入库。
- 素材概览仅在“已入库”视图支持按标签值进行大小写不敏感的包含搜索；待入库素材、名称和描述不得参与匹配。
- 失败必须包含稳定错误码和可操作的中文说明。

## 非功能需求

- 所有应用代码使用 TypeScript strict，不引入 Python。
- 200 MB 上传不得通过 `request.formData()` 整体载入内存。
- SQLite 使用 WAL、忙等待和事务任务抢占。
- 媒体路径必须限制在配置的存储根目录下。
- 素材概览在 1,000 条数据下应在 3 秒内返回首屏分页。

## 范围外

音频素材、音轨分析、ASR、语言识别、字幕输出、URL 上传、批量编辑/删除、缩略图生成、全文搜索、对象存储、Serverless、登录和权限体系。
