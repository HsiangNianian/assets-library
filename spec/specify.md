# 功能规格：多模态素材库 MVP

**功能分支**：`001-multimodal-asset-library`
**状态**：实施中
**技术约束**：Next.js、TypeScript、Tailwind CSS、shadcn/ui、pnpm

## 用户故事

### P1：上传并分析单个本地素材

内容运营人员一次选择一张图片或一个视频，看到真实上传进度、处理状态以及明确失败原因。上传成功后，系统异步生成描述、标签和相应结构化分析。

验收条件：

1. JPEG、PNG、WebP 图片不超过 20 MB 时可提交；结果包含描述、分类标签和 OCR 或不可用原因。
2. H.264 编码的 MP4 不超过 200 MB 时可提交；浏览器提取 1–5 张带时间点的 JPEG 关键帧，结果包含视觉描述、主题、标签、视觉分段、关键时间点和时间轴。
3. 音频、URL、多文件、其他容器、非 H.264 MP4、损坏文件和超限文件被拒绝，并显示具体原因。
4. 视频不足或等于 5 秒时提取 `ceil(时长秒数)` 帧，超过 5 秒时固定提取 5 帧；各帧位于等分区间中点，长视频对应 10%、30%、50%、70%、90%。
5. Responses 协议或禁用视频能力时，视频任务失败为 `model_video_unsupported`，不得转码或静默改用其他分析方案。

### P2：审核、编辑和正式入库

用户可以编辑名称、描述和标签后正式入库，也可以在上传时选择分析完成后直接入库。删除过的模型标签在重新分析后不得自动恢复。

### P3：浏览和维护素材

概览将所有上传成功且未删除的素材分为“待入库”和“已入库”两个视图，每页按 4 列 × 2 行展示 8 个素材。待入库包括排队、分析中、失败以及分析完成待确认的素材，并明确标注状态；分析完成且待审核的素材可在概览直接入库。详情展示原始信息、原文件预览、处理状态、分析结果和最终元数据。

## 功能需求

- 单次只允许用户选择一个本地文件；视频 multipart 请求可附带浏览器生成的关键帧和采样元数据。
- 图片支持 JPEG、PNG、WebP；视频只支持 MP4/H.264。
- 上传限制默认为图片 20 MB、视频 200 MB，并允许环境变量覆盖。
- 处理状态为 `queued`、`validating`、`analyzing`、`completed`、`failed`。
- 审核状态为 `pending_review`、`published`、`deleted`。
- 支持 OpenAI Chat Completions 和 Responses 两种兼容协议。
- 模型配置和密钥只通过环境变量注入。
- Chat Completions 视频分析使用带时间点标注的多图片输入；Responses 默认不支持视频。
- Qwen3.7 结构化素材提取默认关闭思考模式，并允许通过环境变量显式覆盖。
- 视频关键帧由浏览器 Canvas 生成，最长边 1280 像素、JPEG 质量 0.85；服务端校验后随素材持久化，重试时直接复用。
- 支持上传状态、素材分页、详情、编辑、发布、重试、软删除和 Range 媒体读取 API。
- 上传页离开后停止页面轮询，但已入队任务继续由 worker 处理；worker 使用任务心跳并周期恢复失联任务。
- 素材上传成功后立即出现在概览；概览在存在非终态素材时自动刷新，并支持对已完成待审核素材直接入库。
- 素材概览仅在“已入库”视图支持按标签值进行大小写不敏感的包含搜索；待入库素材、名称和描述不得参与匹配。
- 失败必须包含稳定错误码和可操作的中文说明。

## 非功能需求

- 所有应用代码使用 TypeScript strict，不引入 Python。
- 200 MB 上传不得通过 `request.formData()` 整体载入内存。
- SQLite 使用 WAL、忙等待和事务任务抢占。
- 媒体路径必须限制在配置的存储根目录下。
- 素材概览在 1,000 条数据下应在 3 秒内返回首屏分页。

## 范围外

音频素材、音轨分析、ASR、语言识别、字幕输出、URL 上传、批量操作、服务端抽帧、缩略图生成、转码、全文搜索、对象存储、Serverless、登录和权限体系。
